# LAB ESTÁGIO

**Documentação técnica das atividades e projetos desenvolvidos durante o estágio.**

---

## 1. Sobre o projeto

Este repositório tem como finalidade centralizar e documentar as atividades práticas desenvolvidas durante o estágio, registrando procedimentos técnicos, configurações, testes, soluções aplicadas e conhecimentos adquiridos.

A documentação está organizada em ciclos de desenvolvimento, permitindo acompanhar cronologicamente a evolução das atividades e dos projetos.

## 2. Tecnologias e ferramentas

| Categoria | Tecnologias |
|---|---|
| Sistemas operacionais | Ubuntu Desktop e Ubuntu Server |
| Virtualização | VMware Workstation |
| Monitoramento | Zabbix e Grafana |
| Banco de dados | MariaDB / MySQL |
| Redes | TCP/IP, SSH e conectividade de rede |
| Linguagens e consultas | SQL, Bash e Python |

---

## 3. Ciclos de desenvolvimento

### Ciclo 1 — Infraestrutura e Monitoramento

**Escopo:** Semanas 01 a 08

Primeiro ciclo dedicado à preparação do ambiente de laboratório, administração de servidores Linux e implementação de uma estrutura de monitoramento integrada entre Zabbix e Grafana.

| Semana | Atividade | Documentação |
|:---:|---|---|
| 01 | Instalação e configuração do Ubuntu Desktop em máquina virtual | [Acessar](ciclo-1/semana-01-vm-desktop-linux.md) |
| 02 | Estudo e utilização de comandos do terminal Linux | [Acessar](ciclo-1/semana-02-terminal-linux.md) |
| 03 | Instalação do Ubuntu Server, configuração de rede e acesso SSH | [Acessar](ciclo-1/semana-03-ubuntu-server-ssh-rede.md) |
| 04 | Instalação e configuração do Zabbix Server | [Acessar](ciclo-1/semana-04-instalacao-zabbix-server.md) |
| 05 | Instalação do Grafana e integração com o Zabbix | [Acessar](ciclo-1/semana-05-instalacao-grafana.md) |
| 06 | Instalação e configuração do Zabbix Agent na VM Desktop | [Acessar](ciclo-1/semana-06-zabbix-agent-vm-desktop.md) |
| 07 | Criação de triggers, alertas e análise de incidentes | [Acessar](ciclo-1/semana-07-disponibilidade-e-incidentes.md) |
| 08 | Implementação dos indicadores de disponibilidade, MTTR e MTBF no dashboard principal | [Acessar](ciclo-1/semana-08-metricas-de-confiabilidade.md) |

**Resultado do ciclo**

Implementação de um ambiente de monitoramento integrado, permitindo acompanhar indicadores de utilização de CPU, memória RAM, disco e conectividade. Também foram desenvolvidos painéis de alertas e indicadores de disponibilidade e confiabilidade, incluindo MTTR e MTBF.

**Documentação completa:** [Acessar o Ciclo 1](ciclo-1/README.md).

## 4. Padrão de documentação

As documentações seguem uma estrutura padronizada, contemplando:
