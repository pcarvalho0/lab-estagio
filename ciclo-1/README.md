# Ciclo 1 — Infraestrutura e Monitoramento

## Sobre o ciclo

Primeiro ciclo dedicado à construção do ambiente de laboratório, configuração de servidores Linux e implementação de uma estrutura de monitoramento utilizando Zabbix e Grafana.

## Atividades desenvolvidas

| Semana | Atividade |
|:---:|---|
| 01 | Instalação e configuração do Ubuntu Desktop em máquina virtual |
| 02 | Estudo e utilização de comandos do terminal Linux |
| 03 | Instalação do Ubuntu Server, configuração de rede e acesso SSH |
| 04 | Instalação e configuração do Zabbix Server |
| 05 | Instalação do Grafana e integração com o Zabbix |
| 06 | Instalação e configuração do Zabbix Agent na VM Desktop |
| 07 | Criação de triggers, alertas e análise de incidentes |
| 08 | Implementação dos indicadores de disponibilidade, MTTR e MTBF no dashboard principal |

## Resultado do ciclo

Implementação de um ambiente de monitoramento integrado entre Zabbix e Grafana, permitindo acompanhar métricas de CPU, memória RAM, disco e conectividade, visualizar alertas e analisar indicadores de disponibilidade e confiabilidade.
